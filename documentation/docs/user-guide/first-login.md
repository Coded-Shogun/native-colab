# First Login

This guide will walk you through your first login to Native Colab and help you get familiar with the interface.

## Accessing Native Colab

1. Open your web browser and navigate to your Native Colab instance URL
   - Example: `https://colab.yourcompany.com` or `http://localhost:3000` for local development

2. You'll see the login screen with options to:
   - Sign in with email and password
   - Sign in with OAuth providers (if configured)
   - Create a new account

## Default Administrator Credentials

## Creating Your Account

If you're a new user joining an existing workspace:

1. Click **"Create Account"** on the login screen
2. Fill in your details:
   - Full Name
   - Email Address
   - Password (minimum 8 characters)
   - Confirm Password
3. Click **"Sign Up"**
4. Check your email for a verification link
5. Click the verification link to activate your account
6. Return to the login page and sign in

## The Dashboard

After logging in, you'll land on the **Dashboard** - your central hub for all activities.

### Dashboard Components

#### 1. Navigation Bar (Top)
- **Logo**: Click to return to dashboard
- **Search**: Global search across all content
- **Notifications**: Bell icon shows recent notifications
- **Profile Menu**: Access settings and logout

#### 2. Sidebar (Left)
- **Dashboard**: Overview of recent activity
- **Chat**: Access messages and channels
- **Projects**: View and manage projects
- **Documents**: Browse shared documents
- **Time Tracking**: Log time entries
- **Calendar**: Schedule and view events
- **Whiteboard**: Collaborative drawing
- **Meetings**: Video call interface

#### 3. Main Content Area
- **Quick Stats**: Project, task, and message counts
- **Recent Activity**: Latest updates across all modules
- **Your Tasks**: Tasks assigned to you
- **Upcoming Events**: Calendar events
- **Quick Actions**: Shortcuts to common tasks

#### 4. Quick Actions Panel (Right)
- Start a new chat
- Create a project
- Upload a document
- Start time tracking
- Schedule a meeting

## First Steps

### 1. Update Your Profile

1. Click your avatar in the top-right corner
2. Select **"Profile Settings"**
3. Update your information:
   - Profile photo
   - Display name
   - Job title
   - Time zone
   - Language preference
4. Click **"Save Changes"**

### 2. Enable Notifications

1. Go to **Settings** → **Notifications**
2. Configure notification preferences:
   - Email notifications
   - Browser push notifications
   - Mobile push notifications (if using mobile app)
3. Choose which events trigger notifications:
   - Mentions in chat
   - Task assignments
   - Document updates
   - Meeting invitations

### 3. Set Up Two-Factor Authentication (Recommended)

1. Go to **Settings** → **Security**
2. Click **"Enable Two-Factor Authentication"**
3. Scan the QR code with your authenticator app
4. Enter the verification code
5. Save backup codes in a secure location

## Navigation Tips

### Keyboard Shortcuts
- `Ctrl/Cmd + K`: Quick search
- `Ctrl/Cmd + N`: New message
- `Ctrl/Cmd + Shift + N`: New project
- `Ctrl/Cmd + /`: Show all shortcuts

### Search
Use the global search bar to find:
- Messages and conversations
- Projects and tasks
- Documents
- People
- Calendar events

### Quick Switcher
Press `Ctrl/Cmd + K` to open the quick switcher and jump to any:
- Channel or direct message
- Project or task
- Document
- Calendar event

## Common Issues

### Can't Log In?
- Check that your credentials are correct
- Ensure Caps Lock is off
- Try resetting your password

### Email Verification Not Received?
- Check spam/junk folder
- Wait a few minutes (may be delayed)
- Request a new verification email

### Two-Factor Authentication Issues?
- Use backup codes if you lost access to your authenticator
- Contact your administrator for assistance
