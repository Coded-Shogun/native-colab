# Signing Documents Guide

Complete guide to requesting and signing documents electronically using Native Colab's digital signature feature.

## For Document Senders

### Preparing the Document

1. **Create or Upload**: Start with PDF or Word document
2. **Review Content**: Ensure document is final
3. **Identify Signers**: List all who need to sign
4. **Determine Order**: Sequential or parallel signing

### Creating Signature Request

1. Go to Digital Signatures
2. Click "New Signature Request"
3. Upload document
4. Add signers with emails
5. Set signing order if needed
6. Place signature fields
7. Add deadline
8. Include message to signers
9. Send request

### Placing Fields

**Signature Fields:**
- Drag to document
- Assign to specific signer
- Mark as required
- Size appropriately

**Additional Fields:**
- Initial fields for multi-page agreements
- Date fields (auto-filled on signing)
- Text fields for additional info
- Checkboxes for confirmations

### Tracking Progress

**Status Updates:**
- Sent: Waiting for signatures
- Viewed: Signer viewed document
- Signed: Individual signer completed
- Completed: All signers finished

**Actions:**
- Send reminders to pending signers
- View audit trail
- Download partially signed document
- Cancel request if needed

## For Document Signers

### Receiving Request

1. Check email for signature request
2. Click "Review Document" link
3. Log in if required
4. Review document carefully

### Signing Process

1. **Review Document**: Read thoroughly
2. **Navigate Fields**: Follow prompts to each field
3. **Add Signature**: Draw, type, or upload
4. **Complete Other Fields**: Date, initials, text
5. **Review Summary**: Check all fields filled
6. **Confirm and Sign**: Complete the signing

### Creating Your Signature

**Draw:**
- Use mouse, trackpad, or touchscreen
- Draw naturally
- Preview before accepting
- Save for future use

**Type:**
- Enter your name
- Choose font style
- Adjust size if needed
- Save for reuse

**Upload:**
- Have image of signature ready
- Upload image file
- Crop and position
- Save for reuse

### After Signing

- Receive confirmation email
- Download signed document
- Certificate of completion included
- Keep for your records

## Common Scenarios

### Employment Contracts

**Employer:**
1. Upload contract
2. Add employee as signer
3. Add witness if required
4. Set 7-day deadline
5. Track until complete

**Employee:**
1. Review contract carefully
2. Ask questions before signing
3. Sign and date
4. Download copy
5. Keep for records

### Client Agreements

**Service Provider:**
1. Prepare proposal/agreement
2. Send to client
3. Include payment terms
4. Set reasonable deadline
5. Follow up if needed

**Client:**
1. Review services and terms
2. Negotiate if needed
3. Sign when satisfied
4. Receive confirmation
5. Project begins

### NDAs

**Quick Process:**
1. Use NDA template
2. Fill in party names
3. Send for signature
4. Typically same-day completion
5. Both parties receive copy

## Best Practices

### For Senders

1. **Clear Instructions**: Explain what they're signing
2. **Reasonable Deadlines**: Give adequate time
3. **Correct Information**: Verify all details
4. **Professional Message**: Include context
5. **Follow Up**: Gentle reminders if needed

### For Signers

1. **Read Carefully**: Understand what you're signing
2. **Ask Questions**: Before signing if unclear
3. **Keep Copies**: Download signed documents
4. **Prompt Response**: Sign within reasonable time
5. **Professional**: Even for internal documents

### Security

1. **Verify Sender**: Confirm request is legitimate
2. **Secure Connection**: Only sign through official links
3. **Private Information**: Don't share credentials
4. **Save Certificates**: Keep audit trail
5. **Report Issues**: Alert if something seems wrong

## Troubleshooting

### Can't Access Document

- Check spam folder
- Verify email address
- Request resend
- Try different browser
- Check link hasn't expired

### Signature Won't Save

- Clear browser cache
- Try different browser
- Check internet connection
- Use simpler signature
- Contact support

### Wrong Email Address

**Sender:**
- Cancel old request
- Create new request
- Use correct email

**Recipient:**
- Contact sender
- Request resend to correct email
