# Scheduling Meetings Guide

Efficiently schedule and manage meetings using Native Colab's calendar and video call features.

## Quick Meeting Scheduling

### Method 1: Direct Scheduling

1. Click Calendar in sidebar
2. Click date/time slot
3. Fill meeting details
4. Add attendees
5. Enable "Video Call"
6. Send invitations

### Method 2: From Chat

1. In channel or DM
2. Type `/meet` command
3. Choose time
4. Invite participants
5. Meeting created automatically

## Finding the Best Time

### Availability Checker

1. Create meeting
2. Add attendees
3. Click "Find a Time"
4. See combined availability
5. System suggests optimal times
6. Select best time
7. Send invites

### Time Zone Handling

- All times shown in recipient's time zone
- Automatic conversion
- Clearly indicates time zone
- Hover to see all zones

## Meeting Management

### Before the Meeting

1. **Send Agenda**: Share via document or in event description
2. **Prepare Materials**: Upload to event or share in channel
3. **Test Tech**: Audio/video check
4. **Send Reminder**: Automatic reminders or manual nudge

### During the Meeting

1. **Start on Time**: Respect everyone's schedule
2. **Record if Needed**: Ask permission first
3. **Take Notes**: Shared document
4. **Action Items**: Document decisions
5. **Time Management**: Stick to agenda

### After the Meeting

1. **Share Notes**: Post to channel
2. **Share Recording**: If recorded
3. **Action Items**: Create tasks
4. **Follow Up**: Schedule next meeting if needed

## Best Practices

### Scheduling

1. **Buffer Time**: 5-10 minutes between meetings
2. **Respect Hours**: Schedule during work hours
3. **Check Availability**: Before sending invite
4. **Clear Purpose**: State meeting goal
5. **Right Duration**: Not all meetings need an hour

### Invitations

1. **Complete Info**: Title, agenda, attendees
2. **Video Link**: Always include
3. **Materials**: Attach relevant documents
4. **Optional vs Required**: Mark accordingly
5. **Response Requested**: Ask for RSVP

### Meeting Etiquette

1. **Be Punctual**: Join on time
2. **Camera On**: Unless bandwidth issues
3. **Muted by Default**: Unmute to speak
4. **Professional Background**: Or use blur
5. **Stay Engaged**: Minimize distractions
