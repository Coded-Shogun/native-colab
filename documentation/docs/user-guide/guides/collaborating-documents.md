# Collaborating on Documents

Learn how to effectively collaborate on documents with your team in real-time using Native Colab.

## Getting Started

### Sharing Documents

1. Open document
2. Click **"Share"**
3. Choose sharing method:
   - Specific people: Enter emails
   - Anyone with link: Generate link
   - Workspace: Share to workspace
4. Set permission level
5. Send

### Real-Time Editing

- Multiple users can edit simultaneously
- See others' cursors in real-time
- Changes appear instantly
- No save button needed - auto-saves continuously

## Collaboration Features

### Comments

**Adding Comments:**
1. Select text
2. Click comment icon
3. Type comment
4. @mention users for notification
5. Submit

**Resolving Comments:**
- Address the comment
- Mark as resolved
- Reopens if needed

### Suggestions

**Suggesting Mode:**
1. Switch to "Suggesting" mode
2. Make edits
3. Suggestions highlight in color
4. Owner accepts or rejects

## Version Control

### Viewing History

1. Click "Version History"
2. Browse previous versions
3. See who made changes
4. Click to preview

### Restoring Versions

1. Find version to restore
2. Click "Restore"
3. Current version saved as new version
4. Changes can be undone

### Naming Versions

Save important milestones:
1. Open version history
2. Click version
3. Add name (e.g., "Final Draft")
4. Easier to find later

## Best Practices

### Communication

1. **Use Comments**: Don't edit directly, suggest via comments
2. **@Mention**: Tag specific people for input
3. **Resolve Promptly**: Address comments quickly
4. **Clear Feedback**: Be specific in comments

### Organization

1. **One Master**: Single source of truth
2. **Version Names**: Name important versions
3. **Regular Reviews**: Schedule review sessions
4. **Archive Old**: Archive outdated documents

### Workflow

1. **Draft Phase**: Open editing
2. **Review Phase**: Suggestion mode
3. **Final Phase**: Limited editing
4. **Published**: View-only
