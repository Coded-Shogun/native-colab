# Whiteboard

Collaborate visually with Native Colab's interactive whiteboard for brainstorming, diagramming, and visual planning.

## Overview

- Real-time collaborative drawing
- Shapes, text, and sticky notes
- Freehand drawing tools
- Image insertion
- Infinite canvas
- Multiplayer cursors
- Export to PNG/SVG/PDF

## Creating a Whiteboard

1. Click **Whiteboard** in sidebar
2. Click **"New Whiteboard"**
3. Name your board
4. Start creating

## Drawing Tools

- **Select**: Move and resize objects
- **Pen**: Freehand drawing
- **Shapes**: Rectangle, circle, triangle, arrow
- **Text**: Add text boxes
- **Sticky Notes**: Virtual post-its
- **Eraser**: Remove elements
- **Line**: Connect objects

## Collaboration

- Multiple users draw simultaneously
- See others' cursors in real-time
- No conflicts
- Instant updates

## Templates

Pre-built templates:
- Flowchart
- Mind Map
- Wireframe
- Brainstorming
- Kanban Board
- Process Diagram

## Exporting

Export whiteboard as:
- PNG image
- SVG vector
- PDF document
- Share link
