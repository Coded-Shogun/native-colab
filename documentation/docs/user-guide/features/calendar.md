# Calendar & Events

Manage schedules, meetings, and events with Native Colab's integrated calendar system.

## Overview

- Monthly, weekly, and daily views
- Create and manage events
- Meeting scheduling
- RSVP and attendance tracking
- Recurring events
- External calendar sync
- Time zone support
- Reminders and notifications

## Creating Events

1. Click date or time slot
2. Fill event details:
   - Title
   - Date and time
   - Duration
   - Location (physical or virtual)
   - Description
   - Attendees
3. Set event type
4. Add video call link (optional)
5. Save event

## Event Types

- **Meeting**: Team meetings
- **Deadline**: Project milestones
- **Task Due**: Task deadlines
- **Reminder**: Personal reminders
- **Out of Office**: PTO, holidays

## Meeting Scheduling

1. Create meeting event
2. Invite attendees
3. Check availability
4. Find optimal time
5. Send invitations
6. Attendees RSVP

## External Calendar Sync

Sync with:
- Google Calendar
- Microsoft Outlook
- Apple Calendar
- CalDAV

Two-way sync keeps everything updated.
