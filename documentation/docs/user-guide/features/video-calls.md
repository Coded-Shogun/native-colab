# Video & Audio Calls

Native Colab includes built-in video conferencing powered by WebRTC for high-quality, secure calls.

## Overview

- 1-on-1 video calls
- Group video meetings (up to 50 participants)
- Screen sharing
- Audio-only mode
- In-call chat
- Call recording
- Virtual backgrounds (coming soon)

## Starting a Call

### Quick Call

1. Open direct message or channel
2. Click video camera icon
3. Participants receive notification
4. Wait for them to join

### Scheduled Meeting

1. Create calendar event
2. Enable "Video Call"
3. Link generated automatically
4. Attendees can join from event

## During a Call

### Controls

- **Microphone**: Mute/unmute
- **Camera**: Turn video on/off
- **Screen Share**: Share your screen
- **Chat**: Send messages during call
- **Participants**: View participant list
- **Settings**: Audio/video settings
- **Record**: Start/stop recording
- **Leave**: Exit call

### Screen Sharing

1. Click **"Share Screen"**
2. Choose what to share:
   - Entire screen
   - Application window
   - Browser tab
3. Click **"Share"**
4. Click **"Stop Sharing"** when done

### Layouts

- **Grid View**: See all participants equally
- **Speaker View**: Focus on active speaker
- **Presentation Mode**: Large screen share, small videos

## Meeting Features

### Chat

- Send messages during call
- Share links and files
- Messages saved after call
- Private messages to individuals

### Participants

- See who's in the meeting
- Mute others (host only)
- Remove participants (host only)
- Hand raise feature
- Pin specific participant

### Recording

**Start Recording:**
1. Click **"Record"** button
2. Participants notified
3. Recording indicator shows
4. Recording saved automatically

**Access Recordings:**
1. Go to **Meetings** → **Recordings**
2. View, download, or share
3. Delete if no longer needed

## Audio & Video Settings

### Before Joining

Test your setup:
1. Click **"Settings"**
2. Select microphone
3. Select camera
4. Adjust video quality
5. Test audio levels

### During Call

- Switch camera (if multiple)
- Change microphone
- Adjust speaker volume
- Toggle noise cancellation

## Mobile App

Full mobile support:
- Join from phone or tablet
- Same features as desktop
- Picture-in-picture mode
- Background audio

## Best Practices

### Video Etiquette

1. **Mute when not speaking**
2. **Good lighting**: Face a light source
3. **Stable connection**: Use WiFi if possible
4. **Background**: Professional or blurred
5. **Camera angle**: Eye level

### Hosting Meetings

1. **Start on time**
2. **Share agenda** beforehand
3. **Mute all** at start (large meetings)
4. **Take notes** or record
5. **Share recording** afterward

### Technical Tips

1. **Close unused apps**: Free up resources
2. **Wired connection**: More stable than WiFi
3. **Headphones**: Reduce echo
4. **Update browser**: Latest version recommended

## Troubleshooting

### No Audio?
- Check microphone permissions
- Select correct microphone
- Unmute yourself
- Check volume levels

### No Video?
- Check camera permissions
- Select correct camera
- Turn camera on
- Close other apps using camera

### Poor Quality?
- Check internet speed
- Close bandwidth-heavy apps
- Switch to audio-only
- Reduce video quality in settings
