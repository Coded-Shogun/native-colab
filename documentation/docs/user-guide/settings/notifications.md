# Notification Settings

Configure how and when you receive notifications in Native Colab.

## Notification Channels

### Desktop Notifications

Browser notifications:
- Enable/disable
- Notification sound
- Badge counts
- Focus assist integration

### Email Notifications

Email alerts for important events:
- Immediate: Real-time emails
- Digest: Daily or weekly summary
- None: No email notifications

### Mobile Push

Push notifications to mobile app:
- Enable/disable per event type
- Quiet hours
- Priority levels

## Notification Types

### Chat & Messages

- Direct messages
- Channel mentions (@username)
- Channel-wide mentions (@channel)
- Keywords
- Thread replies

### Projects & Tasks

- Task assigned to you
- Task due soon
- Task completed
- Task comments
- Project updates

### Documents

- Document shared with you
- Comments on your documents
- Mentions in comments
- Document updates
- Signature requests

### Calendar

- Meeting invitations
- Meeting reminders (5, 15, 30 min before)
- Event updates
- RSVP changes

### Time Tracking

- Timer running for X hours
- Forgot to track time
- Timesheet approval needed
- Timesheet approved/rejected

## Do Not Disturb

Pause all notifications:
- 30 minutes
- 1 hour
- 2 hours
- Until tomorrow
- Custom schedule

**DND Schedule:**
Set recurring quiet hours:
- Weekdays: 6 PM - 9 AM
- Weekends: All day
- Custom times

## Notification Preferences

### Frequency

- **All activity**: Every notification
- **Important only**: Mentions and assignments
- **Nothing**: Complete silence

### Grouping

- Group similar notifications
- Collapse after X notifications
- Smart bundling
