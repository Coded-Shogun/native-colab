# Security Settings

Protect your account and data with Native Colab's security features.

## Password

### Changing Password

1. Go to **Settings** → **Security**
2. Click **"Change Password"**
3. Enter current password
4. Enter new password
5. Confirm new password
6. Save changes

**Password Requirements:**
- Minimum 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one special character

## Two-Factor Authentication (2FA)

### Enabling 2FA

1. Go to **Security** → **Two-Factor Authentication**
2. Click **"Enable 2FA"**
3. Choose method:
   - Authenticator app (recommended)
   - SMS (if configured)
4. Scan QR code with authenticator app
5. Enter verification code
6. Save backup codes
7. Complete setup

**Authenticator Apps:**
- Google Authenticator
- Microsoft Authenticator
- Authy
- 1Password

### Backup Codes

- 10 single-use backup codes
- Use if you lose access to authenticator
- Download and store securely
- Generate new codes anytime

### Disabling 2FA

1. Go to **Security** → **Two-Factor Authentication**
2. Click **"Disable 2FA"**
3. Enter current password
4. Enter 2FA code
5. Confirm disable

## Active Sessions

View and manage logged-in sessions:

### Session Information

- Device type
- Browser
- IP address
- Location (approximate)
- Last active time

### Managing Sessions

1. View all active sessions
2. Identify unfamiliar sessions
3. Click **"Revoke"** to log out
4. Use **"Revoke All"** for all except current

Third-party apps with access:

1. View connected apps

## API Keys

Personal API keys for integrations:

### Creating API Key

1. Go to **Security** → **API Keys**
2. Click **"Generate Key"**
3. Name the key
4. Set permissions
5. Set expiration (optional)
6. Copy key (shown once!)
7. Store securely

### Managing Keys

- View all keys
- Last used timestamp
- Revoke compromised keys
- Rotate keys regularly

## Best Practices

### Password Security

1. **Unique Password**: Don't reuse passwords
2. **Password Manager**: Use 1Password, LastPass, etc.
3. **Regular Changes**: Update periodically
4. **No Sharing**: Never share credentials

### 2FA Security

1. **Always Enable**: Critical security layer
2. **Backup Codes**: Store securely offline
3. **Authenticator App**: More secure than SMS
4. **Recovery Access**: Keep backup method

### Session Management

1. **Log Out**: Public/shared computers
2. **Regular Review**: Check active sessions
3. **Report Suspicious**: Contact admin immediately
4. **Strong Passwords**: Prevents unauthorized access

### General Security

1. **Update Software**: Keep browser updated
2. **Secure Network**: Use VPN on public WiFi
3. **Lock Screen**: When away from computer
4. **Suspicious Activity**: Report immediately
5. **Phishing Awareness**: Verify links before clicking

## Data & Privacy

### Data Export

Export your personal data:
1. Go to **Settings** → **Privacy**
2. Click **"Export Data"**
3. Select data to export
4. Receive download link
5. Data provided in JSON format

### Account Deletion

Delete your account permanently:
1. Go to **Settings** → **Privacy**
2. Click **"Delete Account"**
3. Type your email to confirm
4. Enter password
5. Confirm deletion

:::danger Warning
Account deletion is permanent and cannot be undone. All your data will be deleted.
:::
