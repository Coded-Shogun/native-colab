# Profile Settings

Customize your personal profile and preferences in Native Colab.

## Personal Information

1. Go to **Settings** → **Profile**
2. Update:
   - Profile photo
   - Display name
   - Email address
   - Job title
   - Department
   - Phone number
   - Bio

## Preferences

### Display

- **Theme**: Light, Dark, or System
- **Language**: Interface language
- **Date Format**: MM/DD/YYYY or DD/MM/YYYY
- **Time Format**: 12-hour or 24-hour

### Time Zone

Set your time zone for accurate scheduling:
- Automatically detected
- Manual selection available
- Affects all date/time displays

## Saved Signatures

Manage saved signatures for documents:
- View saved signatures
- Add new signatures
- Delete old signatures
- Set default signature

## Connected Accounts

Link external accounts:
- Google Account
- Microsoft Account
- GitHub
- GitLab
