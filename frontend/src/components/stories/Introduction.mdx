## What's Inside

### 🎨 Design System
Foundational components that form the building blocks of our UI:
- **Buttons**: Primary, secondary, danger, ghost, and outline variants
- **Inputs**: Form inputs with validation and error states
- **Cards**: Flexible containers for content organization
- **Loading States**: Spinners and skeleton loaders

### 💬 Chat Components
Real-time messaging components:
- Message bubbles
- Channel lists
- Thread views
- Reactions and emoji

### 📋 Project Management
Task and project tracking components:
- Kanban boards
- Task cards
- Project lists
- Timeline views

### 📄 Documents
Collaborative document components:
- Document editor
- File browser
- Version history
- Comment threads

### ⏱️ Time Tracking
Time management components:
- Time entry forms
- Timesheet views
- Timer widgets
- Reports

### 📅 Calendar
Scheduling and event components:
- Calendar grid
- Event cards
- Meeting schedulers
- Availability views

### 🎨 Whiteboard
Collaborative whiteboard components:
- Canvas tools
- Shape libraries
- Drawing tools
- Collaboration cursors

### ✍️ Digital Signatures
Document signing components:
- Signature pads
- Document preview
- Signing workflows
- Verification views

## Getting Started

### For Developers

1. **Browse Components**: Explore the component library in the sidebar
2. **View Variants**: Each component shows different states and variants
3. **Check Props**: See all available props in the "Controls" tab
4. **Test Interactions**: Try different states and configurations
5. **Copy Code**: Use the code snippets for implementation

### For Designers

1. **Design System**: Review consistent styling and spacing
2. **Component States**: See hover, active, disabled, and error states
3. **Responsive Design**: Check components at different sizes
4. **Accessibility**: Components follow WCAG 2.1 AA standards
5. **Dark Mode**: All components support dark mode

### For Marketing

1. **Screenshot Components**: Capture UI examples for sales materials
2. **Feature Showcase**: See all product capabilities
3. **UI Quality**: Demonstrate polished, professional interface
4. **Customization**: Show how components adapt to different needs

## Tech Stack

- **React 18**: Modern React with hooks and concurrent features
- **TypeScript**: Type-safe development
- **Vite**: Lightning-fast build tool
- **Tailwind CSS**: Utility-first styling
- **Radix UI**: Accessible component primitives
- **TanStack Query**: Data fetching and caching
- **TanStack Router**: Type-safe routing

## Accessibility

All components are built with accessibility in mind:
- ✅ Keyboard navigation
- ✅ Screen reader support
- ✅ ARIA attributes
- ✅ Focus management
- ✅ Color contrast (WCAG AA)

Use the **Accessibility** addon (a11y) to check compliance.

## Dark Mode

All components support dark mode out of the box. Toggle the theme using the toolbar.

## Contributing

When adding new components:
1. Create the component in `/src/components/`
2. Add a `.stories.tsx` file
3. Include all variants and states
4. Add accessibility tests
5. Document props and usage
6. Include real-world examples
